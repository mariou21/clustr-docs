# Comunicado de Actualización (v3.0)

> 03/09/2026

Versión: v3.0

Gracias por utilizar CLUSTR. Nos complace presentar la versión 3.0, una actualización que incluye mejoras significativas en operaciones. Con 40 cambios implementados —10 nuevas funcionalidades, 14 optimizaciones de interfaz y rendimiento, y correcciones de datos críticos— hemos trabajado para hacer el sistema más confiable y eficiente.

Destacamos la incorporación del Tablero Kanban para mejor visualización del flujo de cotizaciones y el Selector Dinámico de Fechas y Horas que optimiza la planificación de vuelos. La versión 3.0 está ya disponible en producción.

A continuación, encontrarás el detalle completo de las mejoras implementadas.
